# 👟 SoleMotion — Premium Footwear E-commerce Website

**Move With Intention.**

SoleMotion is a modern, responsive footwear e-commerce website built with React and Vite. It features a premium shopping experience with stylish product displays, smooth animations, product filtering, wishlist management, shopping cart, and a demo checkout flow.

## ✨ Features

- **Modern UI:** Premium footwear branding and a clean, stylish interface.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Hero Section:** Eye-catching product showcase with cinematic sneaker visuals.
- **Product Collection:** Browse Running, Lifestyle, and Training shoes.
- **Search & Filters:** Search by shoe name, category, or colour; filter by price and size.
- **Sorting:** Sort products by price, rating, newest, or featured.
- **Wishlist:** Save favourite shoes and view saved products.
- **Quick View:** View product details, ratings, pricing, and available sizes.
- **Shopping Cart:** Add products, select sizes, update quantities, and remove items.
- **Checkout:** Enter delivery details and select a demo payment method.
- **Order Confirmation:** View a generated order ID and order summary after checkout.
- **Customer Reviews:** Display customer feedback.
- **Newsletter:** Interactive email subscription form.
- **Animations:** Intro animation, hover effects, smooth scrolling, and scroll-triggered reveals.
- **Custom Branding:** SoleMotion logo and browser favicon.

## 🛠️ Technologies Used

- React
- Vite
- JavaScript (ES6+)
- CSS3
- Lucide React
- HTML5
